## Week 1 - History 
- Sumerian Language used syllabic writing.
- Epic of Gilgamesh was early literature (~4,000 years ago).
- Multilingual Inscriptions (Old Persian, Elamite, Babylonian).

## Week 2 - Bits and Bytes
- Bit: Short for binary digit, represents one of two states (0 or 1).
- Byte: Group of 8 bits.
- Binary Numbers: Numbers represented using base 2.

## Week 3 - Text Structure
- Indentation helps in visual understanding.
- Markdown Tags: ```# Title```, ```## Subtitle```, ```_italic_```, ```**bold**```, Lists = ```- item```.
- HTML Tags: ```<ul>```, ```<li>```, ```<p>```, ```<strong>```, ```<h1>```, ```<h2>```, ```<h3>```.

## Week 4 - Keyboards and Editors
- Efficient typing reduces cognitive load.
- Layouts: QWERTY, AZERTY, Dvorak.
- Word Processors (e.g., Microsoft Word) vs. Text Editors (e.g., Notepad).

## Week 5 - Command Line Interfaces
- Commands: ```ls:``` List files in a directory. ```cd:``` Change directory. ```cat:``` Display file contents.
- SSH (Secure Shell): Connect to remote computers securely.
- File Transfer: ```scp:``` Securely copy files between computers. ```sftp:``` Secure file transfer protocol.
